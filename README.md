# ❄️ 극저온의 세계 — 여름방학 과학탐구 캠프 웹앱

중학교 1~2학년 대상 · 3차시(2시간 30분, 쉬는시간 20분 포함) 탐구수업용 웹앱입니다.

---

## 1. 실행 방법

### 가장 좋은 방법 — `시작.bat` 더블클릭
검은 창이 열리고 크롬이 자동으로 실행됩니다. **수업이 끝날 때까지 검은 창을 닫지 마세요.**

- 주소: `http://localhost:8321`
- 같은 PC의 다른 브라우저 창에서도 이 주소로 접속하면 됩니다.
- 끝낼 때는 검은 창에서 `Ctrl + C` 또는 창 닫기.

> Node.js가 설치돼 있어야 합니다. (현재 PC에는 v24 설치 확인됨)

### 급할 때 — `index.html` 더블클릭
설치 없이 바로 열립니다. 다만 이 경우 **무선 센서(블루투스) 연결만 사용할 수 없습니다.**
브라우저 보안 규칙상 블루투스는 `localhost` 또는 `https`에서만 동작하기 때문입니다.
이때는 앱 안의 **「직접 입력하기」** 탭으로 수업을 진행하면 됩니다.

### 태블릿에서 학생들이 쓰게 하려면
같은 와이파이에 연결한 뒤 `server.js`의 `'127.0.0.1'`을 `'0.0.0.0'`으로 바꾸고,
학생 기기에서 `http://<선생님PC IP>:8321` 로 접속합니다.
단, 이 경우는 `https`가 아니라서 **학생 기기에서는 블루투스 센서 연결이 안 됩니다.**
(센서는 선생님 PC 한 대에서 시연하는 것을 권장합니다.)

## 2. 수업 흐름 (총 150분)

| 단계 | 내용 | 시간 |
|---|---|---|
| 0 | 시작하기 (이름 입력·안전 약속) | 5분 |
| 1 | 액화질소란 무엇일까? | 15분 |
| 2 | 극저온에서 일어나는 신기한 현상들 | 10분 |
| 3 | 액화질소를 느껴보자 (라이덴프로스트) | 15분 |
| — | **쉬는 시간** (큰 카운트다운 화면) | 20분 |
| 4 | 액화질소로 놀아보자 (바나나·풍선·용가리·아이스크림) | 30분 |
| 5 | 액화질소로 실험해보자 (냉각곡선 센서 + 향불) | 25분 |
| 6 | 액화질소로 구경하자 (마이스너·부탄) | 15분 |
| 7 | 오늘 배운 것 정리하기 | 5분 |
| 8 | 나의 탐구 보고서 (PDF·메일) | 10분 |

상단 바에 **경과 타이머**가 있고, 쉬는 시간 화면에는 **20분 카운트다운**이 크게 나옵니다.

## 4. 무선 온도 센서 (버니어 Go Direct)

- **크롬(Chrome) 또는 엣지(Edge)** + `시작.bat` 실행 상태에서만 동작합니다. (아이패드 사파리 ✕)
- 5단계 화면에서 `[센서 연결하기]` → 목록에서 **GDX-** 로 시작하는 기기 선택.
- 1초마다 온도를 읽어 **실시간 냉각곡선**을 그립니다.
- `[보고서에 담기]`를 눌러야 보고서 PDF에 그래프와 데이터 표가 들어갑니다.
- 공식 라이브러리 `@vernier/godirect` v1.8.3을 `godirect.js`로 포함했습니다. (인터넷 연결 불필요)

**연결이 안 될 때**는 당황하지 말고 **「직접 입력하기」** 탭에서 시간·온도를 손으로 넣으세요.
숫자를 넣는 즉시 같은 모양의 그래프가 그려지고, 보고서에도 똑같이 들어갑니다.

## 5. 보고서 PDF와 메일

1. 마지막 단계 → `[PDF로 저장하기]` → 인쇄 창에서 프린터를 **「PDF로 저장」**으로 선택.
   - 브라우저 인쇄 기능을 쓰기 때문에 **한글이 깨지지 않습니다.**
2. 메일 주소를 넣고 `[메일 앱 열기]` → 열린 메일에 **저장한 PDF를 첨부**해서 보내면 끝.
   - 웹앱이 파일을 자동 첨부할 수는 없어서(브라우저 보안 제한) 첨부는 직접 해야 합니다.
   - 메일 본문에는 학생이 쓴 답과 측정 데이터가 텍스트로 자동으로 채워집니다.

> 여러 학생이 한 기기를 돌려 쓴다면, 보고서 화면 맨 아래
> `[모두 지우고 새로 시작]`으로 이전 학생 기록을 지워 주세요. (PDF 저장 먼저!)

## 6. 데이터 저장 방식

- 학생이 쓴 글·이름·측정 데이터 → 브라우저 `localStorage`
- 학생이 찍은 사진 → 브라우저 `IndexedDB` (자동으로 1400px로 줄여 저장)
- **새로고침하거나 브라우저를 닫았다 열어도 그대로 남아 있습니다.** 보던 단계까지 기억합니다.
- 서버로 아무것도 전송되지 않습니다. 모든 기록은 그 기기 안에만 있습니다.

## 7. 파일 구성

```
index.html    화면 뼈대
styles.css    디자인 (밝게/어둡게 + 인쇄용 스타일)
content.js    ★ 수업 내용 전체 — 문구를 고치려면 이 파일만 수정
app.js        동작 로직 (저장·사진·센서·그래프·보고서)
godirect.js   버니어 공식 센서 라이브러리
server.js     로컬 서버
시작.bat      실행 버튼
images/       ★ 여기에 사진을 넣으세요
```

수업 문구를 바꾸고 싶으면 **`content.js`만** 열면 됩니다.
`**굵게**` 표시를 쓰면 파란 굵은 글씨가 됩니다.
