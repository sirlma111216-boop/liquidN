# ❄️ 극저온의 세계 — 여름방학 과학탐구 캠프 웹앱

중학교 1~2학년 대상 · 3차시(총 **150분**, 쉬는 시간 10분 × 2회 포함) 탐구수업용 웹앱입니다.
액화질소를 직접 다루며 극저온에서 일어나는 과학 현상을 체험하고, 관찰 내용을 기록해
**보고서 PDF**로 만들어 메일로 제출하는 것까지 한 앱에서 끝납니다.

저장소: <https://github.com/sirlma111216-boop/liquidN>

## 1. 실행 방법

### 방법 A — `시작.bat` 더블클릭 (센서를 쓸 때)

검은 창이 열리고 크롬이 자동으로 실행됩니다. **수업이 끝날 때까지 검은 창을 닫지 마세요.**

- 주소: `http://localhost:8321`
- 같은 PC의 다른 브라우저 창에서도 이 주소로 접속하면 됩니다.
- 끝낼 때는 검은 창에서 `Ctrl + C` 또는 창 닫기.
- Node.js가 필요합니다. (이 PC에는 v24 설치 확인됨)

> **왜 이렇게 실행하나요?**
> 브라우저는 `https://` 또는 `localhost`에서만 블루투스를 허용합니다.
> `index.html`을 그냥 더블클릭하면 주소가 `file:///…`이 되어 **센서 연결이 막힙니다.**

### 방법 B — `index.html` 더블클릭 (센서를 안 쓸 때)

설치 없이 바로 열립니다. **무선 센서 연결만** 사용할 수 없고, 나머지 기능
(기록·사진·보고서·PDF)은 모두 정상 동작합니다.
이때는 온도 실험실의 **「직접 입력하기」** 탭으로 진행하세요.

### 방법 C — 인터넷에 올리기 (아직 안 함)

GitHub Pages를 켜면 `시작.bat` 없이 주소 하나로 접속할 수 있고, `https`라서
**학생 태블릿에서도 센서 연결이 됩니다.** 켜면 주소는
`https://sirlma111216-boop.github.io/liquidN/` 이 됩니다.

### 순서를 바꾸려면

`content.js` 맨 아래 **`LESSON_ORDER`** 목록의 줄 순서만 바꾸면 됩니다.
내용 자체는 손댈 필요가 없습니다. 목록에서 단계를 빠뜨리면 브라우저 콘솔에 경고가 뜹니다.

```js
const LESSON_ORDER = [
  'intro', 's1', 's2', 's3',
  'break',            // 쉬는 시간
  's5',               // 실험해보자
  's4',               // 놀아보자
  'break2',           // 쉬는 시간 2번째
  's6', 'wrap', 'report'
];
```

시간을 바꾸려면 각 단계의 `minutes:` 값을 고치면 됩니다.
화면에 표시되는 총 시간은 **자동으로 다시 계산**됩니다.

## 4. 내용을 고치는 방법 — `content.js` 하나만 보면 됩니다

문구에 `**굵게**`를 쓰면 파란 굵은 글씨가 됩니다.

| 넣고 싶은 것 | 쓰는 법 |
|---|---|
| 문단 | `{ type: 'p', text: '...' }` |
| 소제목 | `{ type: 'h', text: '...' }` |
| 실험 순서 | `{ type: 'steps', items: ['...', '...'] }` |
| 숫자 강조 상자 | `{ type: 'fact', big: '−196 ℃', label: '...', sub: '...' }` |
| 안전 경고 | `{ type: 'danger', items: ['...'] }` |
| 접었다 펴는 설명 | `{ type: 'why', q: '왜 그럴까?', a: '...' }` |
| 두 칸 비교표 | `{ type: 'compare', left: {...}, right: {...} }` |
| 작은 카드 묶음 | `{ type: 'cards', items: [{icon, title, text}] }` |
| 사진 한 장 | `{ type: 'photo', file: '이름.jpg', desc: '설명' }` |
| 사진 여러 장 | `{ type: 'photo', files: [{file, caption}, ...] }` |
| 유튜브 영상 | `{ type: 'video', youtube: '영상ID', vcaption: '설명' }` |

**「왜 그럴까?」 상자 안에 사진과 영상을 함께 넣을 수도 있습니다.**
설명 → 사진 → 영상 순으로 나옵니다.

```js
{ type: 'why',
  q: '어디서 본 적 있는 장면인데?',
  a: '설명 글…',
  files: [{ file: '04-leidenfrost-1.png', caption: '사진 설명' }],
  youtube: 'gjsMV1MglA4' }
```

영상은 상자를 **펼칠 때 비로소 불러옵니다.** 안 열면 유튜브에 접속하지 않으므로
페이지가 무거워지지 않습니다. 인터넷이 안 되면 "유튜브에서 바로 보기" 링크가 표시됩니다.

## 5. 무선 온도 센서 (버니어 Go Direct)

- **크롬(Chrome) 또는 엣지(Edge)** + `시작.bat` 실행 상태에서만 동작합니다. (아이패드 사파리 ✕)
- **4단계 「액화질소로 실험해보자」** 화면에서 `[센서 연결하기]` → 목록에서 **GDX-** 로 시작하는 기기 선택.
- 1초마다 온도를 읽어 **실시간 냉각곡선**을 그립니다. 0℃ 기준선이 자동으로 표시되어
  물이 얼면서 온도가 평평해지는 구간을 학생이 바로 알아볼 수 있습니다.
- `[이 데이터를 보고서에 담기]`를 눌러야 보고서 PDF에 그래프와 데이터 표가 들어갑니다.
- 공식 라이브러리 `@vernier/godirect` v1.8.3을 `godirect.js`로 포함했습니다. (인터넷 연결 불필요)

**연결이 안 될 때**는 당황하지 말고 **「직접 입력하기」** 탭에서 시간·온도를 손으로 넣으세요.
숫자를 넣는 즉시 같은 모양의 그래프가 그려지고, 보고서에도 똑같이 들어갑니다.

## 6. 보고서 PDF와 메일

1. 마지막 단계 → `[PDF로 저장하기]` → 인쇄 창에서 프린터를 **「PDF로 저장」**으로 선택.
   - 브라우저 인쇄 기능을 쓰기 때문에 **한글이 깨지지 않습니다.**
   - 학생이 쓴 답, 찍은 사진, 냉각곡선 그래프와 데이터 표가 모두 자동으로 들어갑니다.
2. 메일 주소를 넣고 `[메일 앱 열기]` → 열린 메일에 **저장한 PDF를 첨부**해서 보내면 끝.
   - 웹앱이 파일을 자동 첨부할 수는 없어서(브라우저 보안 제한) 첨부는 직접 해야 합니다.
   - 메일 본문에는 학생이 쓴 답과 측정 데이터가 텍스트로 자동으로 채워집니다.

> 여러 학생이 한 기기를 돌려 쓴다면, 보고서 화면 맨 아래
> `[모두 지우고 새로 시작]`으로 이전 학생 기록을 지워 주세요. (**PDF 저장 먼저!**)

## 7. 화면 구성

- **데스크탑(1024px 이상)** — 왼쪽에 고정 사이드바(단계 목록 · 진도 막대 · 홈 버튼),
  오른쪽에 본문.
- **16:9 모니터(1440px 이상)** — 본문이 자동으로 **2단**이 됩니다.
  왼쪽은 설명 글, 오른쪽은 「왜 그럴까?」 상자와 사진으로 자리가 **고정**되어 있어서,
  상자를 펼쳐도 다른 박스가 옆으로 튀지 않습니다.
  강조 상자 · 안전 수칙 · 비교표 · 카드 · 온도 실험실은 전체 폭을 씁니다.
- **태블릿·휴대폰(1024px 미만)** — 사이드바가 숨겨지고 상단 **☰ 버튼**으로 열리는 서랍이 됩니다.
  단계를 고르면 자동으로 닫힙니다.
- 오른쪽 위 **🌙 화면** 버튼으로 밝게/어둡게 전환할 수 있습니다. (선택이 기억됩니다)
- **🏠 홈** 버튼은 <https://labbitory.com/lecture-student> 로 이동합니다.

## 8. 데이터 저장 방식

- 학생이 쓴 글 · 이름 · 측정 데이터 → 브라우저 `localStorage`
- 학생이 찍은 사진 → 브라우저 `IndexedDB` (자동으로 1400px로 줄여 저장)
- **새로고침하거나 브라우저를 닫았다 열어도 그대로 남아 있습니다.** 보던 단계까지 기억합니다.
- **서버로 아무것도 전송되지 않습니다.** 모든 기록은 그 기기 안에만 있습니다.
